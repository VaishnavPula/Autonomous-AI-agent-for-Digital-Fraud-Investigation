# Alembic Migrations

## Usage

### Generate a new migration
```bash
cd backend
alembic revision --autogenerate -m "description of changes"
```

### Apply migrations
```bash
cd backend
alembic upgrade head
```

### Rollback migration
```bash
cd backend
alembic downgrade -1
```

### View migration history
```bash
cd backend
alembic history
```

### Show current revision
```bash
cd backend
alembic current
```

## Notes

- Always review autogenerated migrations before applying
- Migration files are in `alembic/versions/`
- Run migrations on startup via `init_db()` in `app/database/session.py`
